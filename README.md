# 本格性格タイプ診断 - Personality Assessment (V2)

心理学および行動特性の理論に基づいた全25問の本格心理・性格タイプ診断Webアプリケーションです。  
スマートフォンおよびPCのどちらでも直感的に操作でき、美しいUI/UX（Mystic & Elegantテーマ）と豊富な分析結果を提供します。

---

## 🌟 主な機能・特徴

1. **基本プロフィールの設定**
   - ネイティブ日付カレンダー（`<input type="date">`）および「年・月・日」ドロップダウンの完全双方向同期。
   - 生年月日に基づく西洋星座・属性エレメントの自動計算。
   - 思考パターンに関わる「利き手」選択および「直感オーラカラー」選択。

2. **全25問の日常行動・心理テスト**
   - 自然で親しみやすい日本語による全25問の質問。
   - 高速連打による誤動作や質問ジャンプを防止するトランジション制御・キー重複防止処理。
   - 進行度が直感的にわかるプログレスバー表示。

3. **全24種類の性格タイプ＆レアカード風キャラクター**
   - 心理学の行動特性（論理、推進、協調、創造、安定）をスコア化し、全24種類の性格タイプに分類。
   - レイヤード発光オーラ、回転リング、アニマル・神秘シンボルを備えたSSRレアカード風キャラクターポートレート。

4. **圧倒的な解像度を誇る詳細分析**
   - **本像と本質**: 多角的な性格の全体像解説。
   - **主な強みと潜在能力**: 伸ばすべき美点と発揮できる才能。
   - **注意点・陥りやすい思考の穴**: トラブルやストレス時に注意すべきポイント。
   - **仕事・適職・働き方スタイル**: 向いている環境、役割、才能が活きる職種。
   - **恋愛・パートナーシップ傾向**: 理想のパートナー像、アプローチ傾向、末永い関係の築き方。
   - **人間関係とコミュニケーション**: 対人関係のスタンスと付き合い方。
   - **開運と成長のアクションアドバイス**: 具体的な自己成長への助言。

5. **詳細な相性診断**
   - **最高の相性（Best Partner）**: お互いを補完し合える相性の理由と長続きのアドバイス。
   - **シナジー相性（Synergy Partner）**: 共に新しい価値を生み出せる相性。
   - **チャレンジ相性（Challenge Partner）**: 価値観が異なり注意が必要な相性と、うまく付き合うための心得。

6. **「私について（AI用プロンプト生成）」機能**
   - 診断されたユーザーの全ステータス、強み・弱み・相性・基本プロフィールを網羅した詳細なカウンセリングプロンプトをワンタップでコピー。
   - GeminiやChatGPTなどのAIに渡すことで、更なる個別深掘り相談やアドバイスを受けられます。

7. **レスポンシブデザイン & 音響演出**
   - スマートフォン（iOS/Android）およびPCのどちらでもデザインが崩れない完全レスポンシブ（Tailwind CSS）。
   - Web Audio APIによるクリック音・演出効果音（ミュート切り替え対応）。
   - ローカルストレージによる過去の診断履歴保存・閲覧機能。

## 🛠 テックスタック

- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Tailwind CSS (Glassmorphism & Mystic Dark Theme)
- **アイコン・効果**: Lucide React, Canvas Confetti
- **オーディオ**: Web Audio API (Synthesizer Engine)
- **デプロイ環境**: Vercel

## 🚀 ローカル開発・ビルド手順

### 開発サーバーの起動
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:3000` にアクセスしてください。

### 生産用ビルド
```bash
npm run build
```
