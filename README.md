# 本格性格タイプ診断 - Personality Assessment

心理学および行動特性の理論に基づいた、全25問の本格的な心理・性格タイプ診断Webアプリケーションです。  
直感的な操作感と美しいダークモダン（Mystic & Elegant）なデザインで、ユーザーの行動傾向・心理特性・適職・恋愛スタイル・相性を精密に分析します。

---

## 🌟 主な特徴・機能

### 1. タッチ＆モバイル最適化された基本入力
- **生年月日入力**: スマートフォン・PCのネイティブカレンダー（`<input type="date">`）と、年・月・日のドロップダウン選択を完全に同期。ストレスなく正確に生年月日を入力できます。
- **直感選択カラー**: 余計なテキスト説明を排除し、カラーパレットから直感で選べるシンプルなUI（黒・無回答を含む）。
- **利き手入力**: 思考回路のバランスを考慮する入力項目。

### 2. 全25問のラフで自然な心理テスト
- 日常生活、仕事、対人関係、買い物、ストレス対応などの具体的な行動パターンを問う25の質問。
- 親しみやすく自然な日本語で構成され、選択肢を選ぶだけでリアルタイムに属性スコアを集計します。

### 3. 全24種類の精細な性格タイプ分類
- 心理学の行動特性（推進力・思考・創造・支援・現実・構想・独立・調和）の組み合わせにより、**全24種類の魅力的な性格タイプ**を導き出します。
- 各タイプには、レア度スター（`★★★★★ SPECIAL`）、アニマル/フェニックス/ドラゴン等の象徴シンボル、称号エンブレムバッジ、テーマグラデーションが割り当てられています。

### 4. ハイクオリティなキャラクターカード表示
- トレーディングカード風のカードデザイン（`CharacterPortraitCard`）で、診断された性格キャラクターを華やかに表示します。

### 5. 5大思考・行動指標ステータスゲージ
- 「論理的思考力」「行動力・推進力」「協調性・共感力」「創造性・独創性」「精神的安定度」の5つのパラメータを100ptスケールで数値化・ビジュアル表示します。

### 6. 多角的でボリューミーな長文解説
- **本質と全体像**: 性格の心理的コアと行動傾向の解説。
- **強みと潜在能力**: 秘められた才能とパフォーマンスを発揮する条件。
- **注意点・陥りやすい穴**: ストレスサインや認知のバイアス。
- **仕事・適職・キャリアのスタイル**: 向いている職種や職場環境。
- **恋愛・パートナーシップ傾向**: 恋愛観や結婚生活のスタイル。
- **開運・成長アクションアドバイス**: 今後の人生をより良くするための具体的行動指針。

### 7. 徹底解説された相性診断
- **最高の相性（ベストパートナー）**: 相性度98%。惹かれ合う理由と長続きの秘訣。
- **補い合う相性（シナジーパートナー）**: 互いの強みを掛け合わせて1+1=3の成果を出すポイント。
- **注意が必要な相性（チャレンジパートナー）**: すれ違いの原因と、衝突を防ぐ具体的コミュニケーションルール。

### 8. 「私について（AI用プロンプト生成）」機能
- ユーザーの生年月日、属性、25問の診断結果、5大ステータス、長所、短所、適職、相性を網羅した高度な**AI分析用プロンプト**を自動生成。
- 1タップでクリップボードにコピーし、ChatGPT・Gemini・Claude等の外部AIチャットに貼り付けて深掘りアドバイスを受けることができます。

### 9. インタラクティブな演出＆サウンドエフェクト
- **Web Audio API**: ボタンタップ音、決定チャイム、ファンファーレを合成音でリアルタイム再生（消音切り替え可能）。
- **紙吹雪演出**: 診断結果表示時のConfettiお祝いアニメーション。
- **ローカル履歴保存**: 過去の診断結果をLocalStorageに保存し、いつでも読み返し・クリアが可能。
- **全24タイプ図鑑**: 全タイプを検索・閲覧できるモーダル機能を搭載。

## 🛠️ 技術スタック

- **フロントエンド**: React 19 / TypeScript / Vite
- **スタイリング**: Tailwind CSS (v4) / グラスモーフィズム（`backdrop-blur`）
- **アイコン体系**: Lucide React
- **演出・アニメーション**: Canvas Confetti / Motion
- **サウンド**: Web Audio API (Synthesizer)

## 🚀 開発・実行手順

### 依存パッケージのインストール
```bash
npm install
```

### 開発サーバーの起動
```bash
npm run dev
```
ブラウザで `http://localhost:3000` にアクセスしてください。

### コードのビルド＆検証
```bash
# 型チェック・リンター
npm run lint

# 本番ビルド
npm run build
```
